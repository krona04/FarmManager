# 🌾 Farm Manager

> **v0.1.0 — Early Access** · From seed to harvest: a full-featured first-person 3D farm with skill progression, trading, and construction.

---

## 🎮 Overview

**Farm Manager** is a first-person 3D farming game where you run your own homestead — planting and harvesting crops, trading at the market, leveling up your skills, and expanding your operation from a modest plot into a thriving farm.

---

## ✨ Features

### 🌱 Farming System

- **Three crop types** — Carrot, Potato, Wheat
- Realistic **growth cycle** with countdown timers
- **Planting mini-game (QTE)** — hit the timing window for a successful sow
- Automatic **harvest calculation** with yield bonuses

### 🏪 Shop & Economy

- **Seed Shop** — buy seeds and sell your harvest
- Three tabs: **Buy / Sell / Decor**
- Open with **[I]** or by interacting with the NPC vendor
- **Dynamic pricing** influenced by the *Sell Bonus* talent and *Trade Network* upgrade

### 🌟 Talent Tree **[T]**

Spend upgrade points (not money) across four branches:

| Talent | Effect per Level |
|---|---|
| Movement Speed | +5% movement speed |
| Growth Speed | −5% crop growth time |
| Sell Bonus | +$5 per unit sold |
| Double Yield | +5% chance for doubled harvest |

### 🏗️ Farm Upgrades (Kiosk)

Purchasable improvements using in-game currency:

| Upgrade | Max Level | Effect |
|---|---|---|
| Extra Plots | 5 | +1 new plot slot per level |
| Growth Booster | 5 | −8% growth time per level |
| Harvest Booster | 3 | +1 unit to every harvest |
| Trade Network | 5 | +$5 to sell price per level |

### 📈 Leveling System

- Earn **XP** through farming actions
- Level-ups reward **upgrade points** for the talent tree
- Current level and balance are displayed on save slots

### 💾 Save System

- **3 independent save slots** showing level, money, and timestamp
- Manual save from the **pause menu** with slot selection
- **Auto-save** on return to the main menu

---

## 🎵 Music System

- Separate tracks for each mode: **gameplay / shop / talents / build**
- **Cross-fade** transitions between modes
- Gameplay track **resumes from the same position** when returning
- Optional **playlist shuffle**
